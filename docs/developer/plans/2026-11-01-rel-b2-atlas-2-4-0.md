## 3. The cap on BEMGen's zones

| Rule part | BEMGen |
| --- | --- |
| `zone_occupant_count_zero` | the zone's People objects' occupant count, summed |
| `other_zone_occupant_count_zero`, `condition_zone` | the People objects of the building's zones whose name or ID is the condition zone; none: not capped, with a warning (the DOE warehouse's office is `Office`, the prototype's `Zone1 Office`) |
| threshold on all lighting | every Lights object's electricity rate, summed, against the threshold times the zone's floor area |
| `set_lights_to_cap` | the first general Lights object set to the cap times the floor area, other general ones to 0 |
| `additional_lighting_when_capped_W_m2` | the other Lights objects set to it times the floor area (the strip mall's 0) |
| `calling_point` | one calling manager per calling point |
| `zone_conditions` | not applied, listed |
| people zero at all times (G4) | not capped, with a warning |
| merged zone, mix | kept only when every source carries the same rule |
