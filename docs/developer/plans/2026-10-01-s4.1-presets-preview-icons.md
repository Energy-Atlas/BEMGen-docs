**Goal:** Implement the Checkpoint 1 review decisions before S5 (D-064): plan generators take one explicit preset per space type, with default preset components per space type that replace *Example Residential Presets* (D-061); every component with a viewport preview gets a *Preview Location* input (D-062); every component and parameter gets a bitmap icon drawn by a script kept in the repository (D-063). Plans, floors, and buildings stay exactly as they are.

**Architecture:** `Lod.Core` gains `PresetValues` (the plain values a preset is built from, with `ToPreset()`) and the generator base `PlanGenerator<TParameters, TPresets>`, whose preset record (`PlanPresets`) lists one `PresetSlot` per space type; every slot is checked before the layout is built (`PresetSpaceTypeMismatch`, `MissingPreset`). `Lod.Generators` adds `LinearPlanPresets(DwellingUnit, Corridor, Stair)`. `ProgramPresetSet` and `DuplicateSpaceType` are deleted. In `Lod.Grasshopper` three thin components (*Dwelling Unit Preset*, *Corridor Preset*, *Stair Preset*) share one base class driven by the `ExampleResidentialPresets` values; the *Linear Plan Generator* gets three preset inputs; `PreviewGoo` carries a preview-only offset read from a shared *Preview Location* input; `scripts/make_icons.py` draws 26 PNG icons that are embedded in the plugin and loaded by `IconLibrary`.

**Tech Stack:** C# 12 (`LangVersion` 12.0); .NET SDK ≥ 8 (`global.json` pins 8.0.100 with `rollForward: latestMajor`); `netstandard2.0` core libraries; Clipper2 2.0.0; RhinoCommon and Grasshopper 8.19.25132.1001 (plugin targets `net7.0`); xUnit 2.9.3, xunit.runner.visualstudio 3.1.5, Microsoft.NET.Test.Sdk 17.14.1 (tests target `net8.0`); Windows PowerShell 5.1 for `scripts/verify.ps1`; Python 3.10 or later with Pillow for `scripts/make_icons.py` (the icons in this plan were drawn with Pillow 12.3.0).

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using Lod.Core.Common;
using Lod.Core.Loads;
using Lod.Core.Schedules;

namespace Lod.Core.Programs;

/// <summary>One load of a <see cref="PresetValues"/>: its type, basis, design value, and fraction schedule.</summary>
/// <param name="Type">Load type.</param>
/// <param name="Basis">Basis the value is expressed per.</param>
/// <param name="Value">Design value in the basis' unit.</param>
/// <param name="Schedule">A fraction schedule multiplying the design magnitude.</param>
public sealed record PresetLoadValue(LoadType Type, LoadBasis Basis, double Value, Schedule Schedule);

/// <summary>
/// The plain values a program preset is built from (D-061): name, space type, window-to-wall ratio, conditioning, constant setpoints, and loads.
/// Change a value with a <c>with</c> expression, then call <see cref="ToPreset"/>.
/// </summary>
/// <param name="Name">Preset name; descriptive only, never used for matching.</param>
/// <param name="SpaceType">The space type the preset applies to.</param>
/// <param name="WindowToWallRatio">WWR in [0, 1) (D-026).</param>
/// <param name="Conditioned">Whether the space is conditioned (D-038); the setpoints are ignored when it is not.</param>
/// <param name="HeatingSetpoint">Constant heating setpoint, °C.</param>
/// <param name="CoolingSetpoint">Constant cooling setpoint, °C.</param>
/// <param name="Loads">Loads; at most one per type and basis (D-047).</param>
public sealed record PresetValues(
    string Name,
    SpaceType SpaceType,
    double WindowToWallRatio,
    bool Conditioned,
    double HeatingSetpoint,
    double CoolingSetpoint,
    IReadOnlyList<PresetLoadValue> Loads)
{
    /// <summary>
    /// Builds the preset. A conditioned preset gets a thermostat of constant temperature schedules named <c>"{Name} Heating Setpoint"</c> and
    /// <c>"{Name} Cooling Setpoint"</c>. Every invalid value is reported, not only the first.
    /// </summary>
    /// <returns>The preset or validation errors.</returns>
    public Result<ProgramPreset> ToPreset()
    {
        var diagnostics = new List<Diagnostic>();
        Result<LoadDefinition>[] loads = Loads.Select(l => LoadDefinition.Create(l.Type, l.Basis, l.Value, l.Schedule)).ToArray();
        diagnostics.AddRange(loads.SelectMany(l => l.Diagnostics));

        Result<Thermostat>? thermostat = Conditioned ? CreateThermostat() : null;
        diagnostics.AddRange(thermostat?.Diagnostics ?? Array.Empty<Diagnostic>());

        bool ready = loads.All(l => l.IsSuccess) && (thermostat?.IsSuccess ?? true);
        Result<ZoneProgram>? program = ready ? ZoneProgram.Create(loads.Select(l => l.Value), thermostat?.Value) : null;
        diagnostics.AddRange(program?.Diagnostics ?? Array.Empty<Diagnostic>());

        // The name and WWR are checked even when the program is invalid, so every error is reported at once.
        ZoneProgram checkedProgram = program is { IsSuccess: true } ? program.Value : ZoneProgram.Create(Array.Empty<LoadDefinition>(), null).Value;
        Result<ProgramPreset> preset = ProgramPreset.Create(Name, SpaceType, checkedProgram, WindowToWallRatio);
        diagnostics.AddRange(preset.Diagnostics);
        return Result.FromDiagnostics(() => preset.Value, diagnostics);
    }

    private Result<Thermostat> CreateThermostat()
    {
        Result<Schedule> heating = Schedule.Constant($"{Name} Heating Setpoint", ScheduleKind.Temperature, HeatingSetpoint);
        Result<Schedule> cooling = Schedule.Constant($"{Name} Cooling Setpoint", ScheduleKind.Temperature, CoolingSetpoint);
        return heating.IsSuccess && cooling.IsSuccess
            ? Thermostat.Create(heating.Value, cooling.Value)
            : Result.Failure<Thermostat>(heating.Diagnostics.Concat(cooling.Diagnostics));
    }
}
```

```csharp
using System.Collections.Generic;
using System.Linq;
using Lod.Core.Common;
using Lod.Core.Geometry;
using Lod.Core.Layout;
using Lod.Core.Model;
using Lod.Core.Programs;

namespace Lod.Core.Plans;

/// <summary>Parameters every plan generator needs. Typology-specific parameters extend this record (spec §6).</summary>
/// <param name="FloorHeight">Floor-to-floor height, m.</param>
/// <param name="OrientationDegrees">Clockwise rotation of plan north from true north, degrees.</param>
public abstract record PlanParameters(double FloorHeight, double OrientationDegrees);

/// <summary>A zone proposed by a generator's layout step.</summary>
/// <param name="Id">Zone ID.</param>
/// <param name="Name">Display name.</param>
/// <param name="SpaceType">Space type; selects the program preset.</param>
/// <param name="Footprint">Zone polygon.</param>
public sealed record PlannedZone(ZoneId Id, string Name, SpaceType SpaceType, Polygon2 Footprint);

/// <summary>The geometric output of a generator's layout step.</summary>
/// <param name="Footprint">Plan boundary.</param>
/// <param name="Zones">Zones tiling the footprint.</param>
public sealed record PlanLayout(Polygon2 Footprint, IReadOnlyList<PlannedZone> Zones);

/// <summary>
/// Base class of plan generators (spec §5). Subclasses only validate their parameters and lay out zones; this class assigns program presets,
/// builds surfaces, places centered windows from each preset's WWR, and records provenance. Generation is deterministic.
/// </summary>
/// <typeparam name="TParameters">The generator's parameter record.</typeparam>
/// <typeparam name="TPresets">The generator's preset record, one preset per space type it places (D-061).</typeparam>
public abstract class PlanGenerator<TParameters, TPresets>
    where TParameters : PlanParameters
    where TPresets : PlanPresets
{
    /// <summary>Initialises the generator.</summary>
    /// <param name="tolerances">Tolerances.</param>
    protected PlanGenerator(ToleranceSettings tolerances)
    {
        Tolerances = tolerances;
    }

    /// <summary>Operation name recorded in provenance.</summary>
    public abstract string Name { get; }

    /// <summary>Tolerances.</summary>
    protected ToleranceSettings Tolerances { get; }

    /// <summary>Generates a detailed plan.</summary>
    /// <param name="parameters">Generator parameters.</param>
    /// <param name="presets">Program presets, one per slot; each must have its slot's space type.</param>
    /// <returns>The plan, or errors.</returns>
    public Result<IGeneratedPlan> Generate(TParameters parameters, TPresets presets)
    {
        var diagnostics = new List<Diagnostic>();
        if (!IsPositive(parameters.FloorHeight))
        {
            diagnostics.Add(Diagnostic.Error(DiagnosticCodes.InvalidParameter, $"FloorHeight must be positive, got {parameters.FloorHeight}."));
        }

        if (double.IsNaN(parameters.OrientationDegrees) || double.IsInfinity(parameters.OrientationDegrees))
        {
            diagnostics.Add(Diagnostic.Error(DiagnosticCodes.InvalidParameter, $"OrientationDegrees must be finite, got {parameters.OrientationDegrees}."));
        }

        diagnostics.AddRange(Validate(parameters));
        diagnostics.AddRange(CheckSlots(presets.Slots));
        if (diagnostics.Count > 0)
        {
            return Result.Failure<IGeneratedPlan>(diagnostics);
        }

        PlanLayout layout = Layout(parameters);
        var zones = new List<Zone>();
        foreach (PlannedZone planned in layout.Zones)
        {
            ProgramPreset? preset = Find(presets, planned.SpaceType);
            if (preset is null)
            {
                diagnostics.Add(Diagnostic.Error(DiagnosticCodes.MissingPreset, $"No program preset for space type {planned.SpaceType}.", planned.Id.Value));
                continue;
            }

            zones.Add(new Zone(planned.Id, planned.Name, planned.SpaceType, new[] { new ZonePart(planned.Footprint, 0.0, parameters.FloorHeight) }, preset.Program, Enumerable.Empty<ZoneId>()));
        }

        if (diagnostics.Count > 0)
        {
            return Result.Failure<IGeneratedPlan>(diagnostics);
        }

        Result<IReadOnlyList<Surface>> surfaces = new LayoutSurfaceBuilder(Tolerances)
            .Build(layout.Footprint, layout.Zones.Select(z => new LayoutZone(z.Id, z.Footprint)).ToArray(), parameters.FloorHeight);
        if (!surfaces.IsSuccess)
        {
            return Result.Failure<IGeneratedPlan>(surfaces.Diagnostics);
        }

        Dictionary<ZoneId, double> ratios = layout.Zones.ToDictionary(z => z.Id, z => Find(presets, z.SpaceType)!.WindowToWallRatio);
        IReadOnlyList<Surface> withWindows = LayoutMeasures.PlaceWindowsByRatio(surfaces.Value, id => ratios[id]);
        IEnumerable<KeyValuePair<string, string>> recorded = Describe(parameters)
            .Concat(new[]
            {
                new KeyValuePair<string, string>(nameof(PlanParameters.FloorHeight), Provenance.Format(parameters.FloorHeight)),
                new KeyValuePair<string, string>(nameof(PlanParameters.OrientationDegrees), Provenance.Format(parameters.OrientationDegrees)),
                new KeyValuePair<string, string>("Presets", string.Join(";", presets.Slots.Select(s => $"{s.Preset.SpaceType}:{s.Preset.Name}"))),
            });
        var plan = new GeneratedPlan(layout.Footprint, parameters.FloorHeight, parameters.OrientationDegrees, zones, withWindows, Provenance.Of(Name, recorded));
        return Result.Success<IGeneratedPlan>(plan);
    }

    /// <summary>Checks typology-specific parameters.</summary>
    /// <param name="parameters">Parameters.</param>
    /// <returns>Errors, if any.</returns>
    protected abstract IEnumerable<Diagnostic> Validate(TParameters parameters);

    /// <summary>Lays out zones for valid parameters.</summary>
    /// <param name="parameters">Validated parameters.</param>
    /// <returns>Footprint and zones.</returns>
    protected abstract PlanLayout Layout(TParameters parameters);

    /// <summary>Typology-specific parameters for provenance, as invariant-culture text.</summary>
    /// <param name="parameters">Parameters.</param>
    /// <returns>Key-value pairs.</returns>
    protected abstract IEnumerable<KeyValuePair<string, string>> Describe(TParameters parameters);

    private static IEnumerable<Diagnostic> CheckSlots(IEnumerable<PresetSlot> slots)
    {
        foreach (PresetSlot slot in slots)
        {
            if (slot.Preset is null)
            {
                yield return Diagnostic.Error(DiagnosticCodes.MissingPreset, $"Input {slot.Input} needs a {slot.SpaceType} preset, got none.", slot.Input);
            }
            else if (slot.Preset.SpaceType != slot.SpaceType)
            {
                yield return Diagnostic.Error(
                    DiagnosticCodes.PresetSpaceTypeMismatch,
                    $"Input {slot.Input} needs a {slot.SpaceType} preset, got '{slot.Preset.Name}' ({slot.Preset.SpaceType}).",
                    slot.Input);
            }
        }
    }

    private static ProgramPreset? Find(TPresets presets, SpaceType spaceType) =>
        presets.Slots.FirstOrDefault(s => s.SpaceType == spaceType)?.Preset;

    /// <summary>Whether a value is finite and positive.</summary>
    /// <param name="value">The value.</param>
    /// <returns><c>true</c> when positive and finite.</returns>
    protected static bool IsPositive(double value) => value > 0 && !double.IsInfinity(value);
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.Linq;
using Grasshopper.Kernel;
using Lod.Core.Loads;
using Lod.Core.Programs;
using Lod.Grasshopper.Goo;
using Lod.Grasshopper.Parameters;

namespace Lod.Grasshopper.Components;

/// <summary>
/// Shared inputs and solving of the default preset components (D-061): one component per space type whose inputs all default to its
/// <see cref="PresetValues"/>, so it works with nothing connected. Inputs: Name, WWR, Conditioned, Heating, Cooling, then a value and an optional
/// schedule per load of the defaults, in their order.
/// </summary>
public abstract class DefaultPresetComponent : GH_Component
{
    private const string IllustrativeRemark = "Illustrative values; not sourced from DOE prototypes or standards.";
    private const int FirstLoadInput = 5;

    protected DefaultPresetComponent(string name, string nickname, string description)
        : base(name, nickname, description, ComponentCategories.Category, ComponentCategories.Program)
    {
    }

    protected override Bitmap? Icon => null;

    /// <summary>The default values; read while inputs are registered, so they must not depend on instance state.</summary>
    protected abstract PresetValues Defaults { get; }

    protected override void RegisterInputParams(GH_InputParamManager pManager)
    {
        PresetValues defaults = Defaults;
        pManager.AddTextParameter("Name", "N", "Preset name; descriptive only (reports, provenance, messages), never used for matching.", GH_ParamAccess.item, defaults.Name);
        pManager.AddNumberParameter("WWR", "WWR", "Window-to-wall ratio in [0, 1) used by the plan generator for every exterior wall.", GH_ParamAccess.item, defaults.WindowToWallRatio);
        pManager.AddBooleanParameter("Conditioned", "Cond", "Whether the space is conditioned (D-038); the setpoints are ignored when it is not.", GH_ParamAccess.item, defaults.Conditioned);
        pManager.AddNumberParameter("Heating", "H", "Constant heating setpoint, °C.", GH_ParamAccess.item, defaults.HeatingSetpoint);
        pManager.AddNumberParameter("Cooling", "C", "Constant cooling setpoint, °C.", GH_ParamAccess.item, defaults.CoolingSetpoint);
        foreach (PresetLoadValue load in defaults.Loads)
        {
            (string label, string nickname) = LoadLabel(defaults.Loads, load);
            pManager.AddNumberParameter(label, nickname, $"{label} design value, {Unit(load.Type, load.Basis)}.", GH_ParamAccess.item, load.Value);
            int schedule = pManager.AddParameter(
                new ScheduleParameter(),
                $"{label} Schedule",
                nickname + "S",
                $"Optional fraction schedule of {label}; replaces the built-in schedule '{load.Schedule.Name}' when connected.",
                GH_ParamAccess.item);
            pManager[schedule].Optional = true;
        }
    }

    protected override void RegisterOutputParams(GH_OutputParamManager pManager)
    {
        pManager.AddParameter(new ProgramPresetParameter(), "Preset", "P", "The program preset.", GH_ParamAccess.item);
    }

    protected override void SolveInstance(IGH_DataAccess DA)
    {
        AddRuntimeMessage(GH_RuntimeMessageLevel.Remark, IllustrativeRemark);
        PresetValues defaults = Defaults;
        string name = string.Empty;
        double wwr = 0.0;
        bool conditioned = false;
        double heating = 0.0;
        double cooling = 0.0;
        if (!DA.GetData(0, ref name) || !DA.GetData(1, ref wwr) || !DA.GetData(2, ref conditioned) || !DA.GetData(3, ref heating) || !DA.GetData(4, ref cooling))
        {
            return;
        }

        var loads = new PresetLoadValue[defaults.Loads.Count];
        for (int k = 0; k < loads.Length; k++)
        {
            double value = 0.0;
            ScheduleGoo? schedule = null;
            if (!DA.GetData(FirstLoadInput + (2 * k), ref value))
            {
                return;
            }

            DA.GetData(FirstLoadInput + (2 * k) + 1, ref schedule);
            loads[k] = defaults.Loads[k] with { Value = value, Schedule = schedule?.Value ?? defaults.Loads[k].Schedule };
        }

        PresetValues values = defaults with
        {
            Name = name,
            WindowToWallRatio = wwr,
            Conditioned = conditioned,
            HeatingSetpoint = heating,
            CoolingSetpoint = cooling,
            Loads = loads,
        };
        ProgramPreset? preset = ComponentSupport.Unwrap(this, values.ToPreset());
        if (preset is not null)
        {
            DA.SetData(0, new ProgramPresetGoo(preset));
        }
    }

    /// <summary>Input name and nickname of a load; the basis is added when the defaults hold the load type in more than one basis (D-047).</summary>
    private static (string Label, string Nickname) LoadLabel(IReadOnlyList<PresetLoadValue> loads, PresetLoadValue load)
    {
        (string label, string nickname) = load.Type switch
        {
            LoadType.Occupancy => ("Occupancy", "Occ"),
            LoadType.Lighting => ("Lighting", "Lt"),
            LoadType.ElectricEquipment => ("Equipment", "Eq"),
            LoadType.GasEquipment => ("Gas Equipment", "Gas"),
            LoadType.DomesticHotWater => ("Hot Water", "DHW"),
            LoadType.Ventilation => ("Ventilation", "Vent"),
            _ => ("Infiltration", "Inf"),
        };
        return loads.Count(l => l.Type == load.Type) > 1
            ? ($"{label} {load.Basis}", nickname + string.Concat(load.Basis.ToString().Where(char.IsUpper)))
            : (label, nickname);
    }

    /// <summary>Unit of a load value: the magnitude unit of its type (people, W, m³/h) per its basis (ADR-007).</summary>
    private static string Unit(LoadType type, LoadBasis basis)
    {
        string magnitude = type switch
        {
            LoadType.Occupancy => "people",
            LoadType.Lighting or LoadType.ElectricEquipment or LoadType.GasEquipment => "W",
            _ => "m³/h",
        };
        return basis switch
        {
            LoadBasis.PerFloorArea => $"{magnitude}/m²",
            LoadBasis.PerPerson => $"{magnitude}/person",
            LoadBasis.PerExteriorWallArea => $"{magnitude}/m² of exterior wall",
            LoadBasis.AirChangesPerHour => "1/h (air changes per hour)",
            _ => magnitude,
        };
    }
}
```

```csharp
using System.Collections.Generic;
using System.Linq;
```

```csharp
/// <summary>Adapters between core diagnostics and Grasshopper runtime messages, text-to-enum input parsing, and the shared Preview Location input.</summary>
internal static class ComponentSupport
{
    private const string PreviewLocationName = "Preview Location";
    private const string PreviewLocationNickname = "PL";
    private const string PreviewLocationDescription =
        "Moves this component's viewport preview by this vector, in model units; the data and all outputs keep their true coordinates (D-062).";

    /// <summary>Adds each diagnostic as a runtime message: errors as errors, warnings as warnings, info as remarks.</summary>
    public static void Report(GH_Component component, IEnumerable<Diagnostic> diagnostics)
    {
        foreach (Diagnostic diagnostic in diagnostics)
        {
            GH_RuntimeMessageLevel level = diagnostic.Severity switch
            {
                DiagnosticSeverity.Error => GH_RuntimeMessageLevel.Error,
                DiagnosticSeverity.Warning => GH_RuntimeMessageLevel.Warning,
                _ => GH_RuntimeMessageLevel.Remark,
            };
            component.AddRuntimeMessage(level, diagnostic.ToString());
        }
    }

    /// <summary>Reports the diagnostics and returns the value, or <c>null</c> on failure.</summary>
    public static T? Unwrap<T>(GH_Component component, Result<T> result)
        where T : class
    {
        Report(component, result.Diagnostics);
        return result.IsSuccess ? result.Value : null;
    }

    /// <summary>Parses an enum name case-insensitively; on failure adds an error listing the valid names.</summary>
    public static bool TryParse<TEnum>(GH_Component component, string text, out TEnum value)
        where TEnum : struct
    {
        if (Enum.TryParse(text?.Trim(), ignoreCase: true, out value) && Enum.IsDefined(typeof(TEnum), value))
        {
            return true;
        }

        component.AddRuntimeMessage(
            GH_RuntimeMessageLevel.Error,
            $"'{text}' is not a valid {typeof(TEnum).Name}. Use one of: {string.Join(", ", Enum.GetNames(typeof(TEnum)))}.");
        return false;
    }

    /// <summary>The valid names of an enum, for input descriptions.</summary>
    public static string Names<TEnum>() => string.Join(", ", Enum.GetNames(typeof(TEnum)).Select(n => n));

    /// <summary>
    /// The optional Preview Location input (D-062), default zero. Register it last, <c>pManager.AddParameter(ComponentSupport.PreviewLocationParameter())</c>,
    /// so <see cref="PreviewLocation"/> finds it as the component's last input.
    /// </summary>
    public static IGH_Param PreviewLocationParameter()
    {
        var parameter = new Param_Vector
        {
            Name = PreviewLocationName,
            NickName = PreviewLocationNickname,
            Description = PreviewLocationDescription,
            Access = GH_ParamAccess.item,
            Optional = true,
        };
        parameter.SetPersistentData(new GH_Vector(Vector3d.Zero));
        return parameter;
    }

    /// <summary>Reads the Preview Location input, the component's last input; zero when it holds no vector.</summary>
    public static Vector3d PreviewLocation(GH_Component component, IGH_DataAccess DA)
    {
        Vector3d offset = Vector3d.Zero;
        return DA.GetData(component.Params.Input.Count - 1, ref offset) ? offset : Vector3d.Zero;
    }
}
```

```csharp
/// <summary>
/// Wrapper with viewport preview: zones coloured by space type, windows in blue. The preview is moved by <see cref="PreviewOffset"/> (D-062); the
/// wrapped value keeps its true coordinates.
/// </summary>
/// <typeparam name="T">Wrapped type.</typeparam>
public abstract class PreviewGoo<T> : BemGoo<T>, IGH_PreviewData
    where T : class
{
    private static readonly Color WindowColour = Color.FromArgb(70, 140, 220);
    private List<(Brep Brep, DisplayMaterial Material)>? _preview;

    protected PreviewGoo(T value, Vector3d previewOffset)
        : base(value)
    {
        PreviewOffset = previewOffset;
    }

    /// <summary>Translation of the viewport preview only, in model units (D-062).</summary>
    public Vector3d PreviewOffset { get; }

    public BoundingBox ClippingBox
    {
        get
        {
            BoundingBox box = BoundingBox.Empty;
            foreach ((Brep brep, DisplayMaterial _) in Preview)
            {
                box.Union(brep.GetBoundingBox(false));
            }

            return box;
        }
    }

    private List<(Brep Brep, DisplayMaterial Material)> Preview => _preview ??= BuildPreview();

    public void DrawViewportMeshes(GH_PreviewMeshArgs args)
    {
        foreach ((Brep brep, DisplayMaterial material) in Preview)
        {
            args.Pipeline.DrawBrepShaded(brep, material);
        }
    }

    public void DrawViewportWires(GH_PreviewWireArgs args)
    {
        foreach ((Brep brep, DisplayMaterial _) in Preview)
        {
            args.Pipeline.DrawBrepWires(brep, args.Color);
        }
    }

    protected abstract IEnumerable<Zone> Zones { get; }

    protected abstract IEnumerable<Surface> Surfaces { get; }

    private List<(Brep, DisplayMaterial)> BuildPreview()
    {
        var items = new List<(Brep, DisplayMaterial)>();
        foreach (Zone zone in Zones)
        {
            var material = new DisplayMaterial(SpaceTypeColour(zone.SpaceType), 0.6);
            items.AddRange(RhinoGeometry.ZoneBreps(zone).Select(b => (b, material)));
        }

        var glass = new DisplayMaterial(WindowColour, 0.2);
        foreach (WallSurface wall in Surfaces.OfType<WallSurface>())
        {
            items.AddRange(RhinoGeometry.WindowBreps(wall).Select(b => (b, glass)));
        }

        if (!PreviewOffset.IsZero)
        {
            Transform move = Transform.Translation(PreviewOffset);
            foreach ((Brep brep, DisplayMaterial _) in items)
            {
                brep.Transform(move);
            }
        }

        return items;
    }

    private static Color SpaceTypeColour(SpaceType type) => type switch
    {
        SpaceType.DwellingUnit => Color.FromArgb(240, 200, 120),
        SpaceType.Corridor => Color.FromArgb(180, 180, 180),
        SpaceType.Stair => Color.FromArgb(200, 120, 120),
        SpaceType.Core => Color.FromArgb(160, 120, 200),
        SpaceType.Mixed => Color.FromArgb(120, 190, 160),
        _ => Color.FromArgb(150, 170, 200),
    };
}
```

```csharp
using System.Collections.Concurrent;
using System.Drawing;
using System.IO;

namespace Lod.Grasshopper;

/// <summary>
/// The embedded 24 × 24 icons (D-063), drawn by <c>scripts/make_icons.py</c> into <c>Icons/&lt;class name&gt;.png</c>.
/// </summary>
/// <remarks>
/// A missing icon returns <c>null</c>, which Grasshopper shows as its default icon: an exception in an <c>Icon</c> getter would surface while Grasshopper
/// loads the toolbar, far from its cause. Completeness is checked where it can fail fast instead: <c>make_icons.py</c> stops when a component or
/// parameter class has no icon.
/// </remarks>
internal static class IconLibrary
{
    private static readonly ConcurrentDictionary<string, Bitmap?> Cache = new();

    /// <summary>The icon of a component, parameter, or the assembly info, looked up by its class name.</summary>
    public static Bitmap? For(object owner) => Cache.GetOrAdd(owner.GetType().Name, Load);

    private static Bitmap? Load(string name)
    {
        using Stream? stream = typeof(IconLibrary).Assembly.GetManifestResourceStream($"{typeof(IconLibrary).Namespace}.Icons.{name}.png");
        if (stream is null)
        {
            return null;
        }

        using var image = Image.FromStream(stream);
        return new Bitmap(image);
    }
}
```

```csharp
            LoadBasis.PerExteriorWallArea => $"{magnitude}/m² of exterior wall",
            LoadBasis.AirChangesPerHour => "1/h (air changes per hour)",
            _ => magnitude,
        };
    }
```

## Notes for the reviewer

1. **Source.** Every code block was taken from a verified reference implementation built on `main` at `8c6feaa` (D-061 to D-064), one commit per task, in the order of this plan. Each intermediate state was built and tested: the red errors of Tasks 1–3 (including line and column numbers), the intermediate errors of Task 3 Steps 11 and 14, the counts 109 / 117 / 120 core and 19 generators, and a 0-warning build after every task are observed results. The 26 PNGs were regenerated from the plan's `make_icons.py` with Pillow 12.3.0 and are byte-identical to the reference (Task 7, Step 4).
2. **Slices and branches.** The roadmap has no slice list for S4.1; this plan uses five slices and a close-out, named after D-004: `feature/programs-preset-values`, `feature/generators-typed-presets`, `feature/grasshopper-preset-components`, `feature/grasshopper-preview-location`, `feature/grasshopper-icons`, `docs/architecture-presets-preview-icons`, and `chore/repo-s4.1-close-out`. Merges rebase onto local `main` and never push; the person approves every push (execution handoff §6). The unsupervised-run push rule of D-054 does not apply to S4.1.
3. **A null preset is a `MissingPreset`, not a new code.** The design brief left the choice open. `MissingPreset` already means "no preset for what the generator needs"; its summary is widened to cover an empty slot. The subject is the input name (`Stair`), while a layout space type without a slot keeps the zone ID as subject (`C1`). The Grasshopper component never passes a null preset: an unconnected input stops the component before the core is called (note 4).
4. **Unconnected preset input: a warning in Grasshopper, not an error (D-065).** The generator's preset inputs are required (not optional), so Grasshopper itself reports `Input parameter St failed to collect data` as a **warning** and the component outputs nothing, which is how every required input of every BEMGen component behaves since S2. There is no silent fallback. The owner confirmed this behaviour (D-065, refining D-061's "missing-input error").
5. **The mismatch message uses the core slot name.** The error reads `Input DwellingUnit needs a DwellingUnit preset, got 'Example Corridor' (Corridor).`: the input name comes from `LinearPlanPresets` (`nameof(DwellingUnit)`), not from the Grasshopper input *Dwelling Unit* (DU). The message is the same in code and in Grasshopper; S9 (UX) may map it to the Grasshopper name.
6. **Setpoint schedule names changed.** `PresetValues` names the constant setpoint schedules after the preset (`"Example Dwelling Unit Heating Setpoint"` instead of the shared `"Example Heating Setpoint"`). Values are unchanged; no snapshot, validation check, or *Convert2BEM* output contains the names. `docs/research/program-presets.md` §2 shows the new names (Task 9).
7. **A missing icon returns `null`.** An exception in an `Icon` getter would surface while Grasshopper builds its toolbar, far from its cause, and could hide the whole plugin. Completeness is enforced where it can fail fast: `make_icons.py` exits with code 1 when a component or parameter class has no icon, an icon has no class, or a stale PNG remains. The check finds classes with the pattern `public sealed class X : Y`; a non-sealed component class would escape it (all are sealed today).
8. **Icons for parameters and the assembly info.** D-063 asks for an icon per component; parameters (shown in tooltips and the *Params* search) and the plugin get one too, 26 in all. A parameter uses the accent of the panel that makes its object (Plan: Generate, Floor: Simplify, Building: Aggregate), although the parameters are registered, hidden, in *0 Info*. The PNGs are generated files; the script's header names the Pillow version that produced them. `check_plans.py` flags the docstring line that names this Pillow version as a possible attribution; it is a known false positive (it names the image library, not an author).
9. **Default preset inputs have defaults but are not marked optional.** The design brief asked for optional inputs with defaults; D-061 asks that every input has a default so the component works with nothing connected. The reference registers the inputs with persistent default values (not `Optional`), which satisfies D-061: an input with persistent data always collects data. Only the schedule inputs are optional, because they have no default.
10. **`DuplicateSpaceType` is deleted, not deprecated.** `DiagnosticCodes` says "never reuse or rename a published code". Deleting the code is neither reuse nor rename, and D-064 allows deletion without migration. Task 8 rewords the domain-model sentence "later stages only append codes" to "a removed code's name is not reused" (owner's decision).
11. **Tests changed, not only added.** Two S1 tests (`PresetSetRejectsDuplicateSpaceTypes`, `ExamplePresetsCoverTheLinearPlanSpaceTypes`) are deleted with the type they test, and `MissingPresetIsAnError` (S2) now uses a null stair and expects the subject `Stair` instead of `ST`. Their coverage moves to `ExampleResidentialPresetsTests` and `PlanGeneratorTests`. No snapshot changes.
12. **Task 3 touches three projects in one commit** because deleting `ProgramPresetSet` breaks `Lod.Generators` and `Lod.Grasshopper` at once; splitting it would leave `main` unbuildable between commits. The intermediate *Example Residential Presets* change in Step 14 exists only to keep the plugin building until Task 5 deletes the component.
13. **Preview offset in model units.** `RhinoGeometry` builds Breps in metres and scales them to model units; the offset is added after that, so *Preview Location* is in model units, as D-062 says (smoke test item 9, millimetre document). The offset is not stored in the plan, floor, or building, so a component downstream previews at the true position unless it has its own offset.
14. **Commit type of Task 5.** Removing *Example Residential Presets* is committed as `refactor(grasshopper): …`, as in the reference; AGENTS.md has no type for a removal, and the default preset components that replace it come in Task 4 (`feature`).
