## 2. Approach

1. Re-export the program and construction fixtures from an atlas clone at `75fec30d` (`export_fixtures.py --release 2.3.0`), see the readers fail on the new versions, then move the readers and the embedded schemas.
2. Re-record the sites, then the site-dependent tests.
3. F1 test first (`DoeAtlasFoldersTests` failing to compile on `FamiliesOf`/`Holds`), then `DoeAtlasFolders`, then the integration tests on the recorded index.
4. Schedule Draw: the pins, the release 2.3.0 generation files, the draws recorded again with `python -m atlas_schedules` in the atlas clone, two new recorded draws (detailed office, IECC).
5. The stored-release refusals test first (shown failing with the check disabled).
